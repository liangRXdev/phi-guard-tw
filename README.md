# phi-guard-tw

Claude Code mod（function hooks）。在模型讀到之前，強制遮罩格式固定的台灣病患識別欄位，把「靠模型記得遮罩」改成「程式強制」。

## 守什麼

| 位置 | 機制 | 行為 |
|---|---|---|
| 寫進對話的每一列（工具結果、MCP、附件、提問、子代理的對話） | `session.append` | 遮罩後才儲存與送出；狀態列顯示本 session 累計遮罩數 |
| 你的提問 | `prompt.submit` | 送出前遮罩；toast 只報類型與數量，不顯示原值 |
| 工具呼叫 | `tool.call` | ① 敏感目錄（`00_private`、`raw`、`private`、`phi`）下的圖片／PDF 擋下 ② 非讀取類工具的輸入含遮罩字樣時擋下（避免把遮罩值寫回來源、損毀原檔） |

**失敗時的預設是擋下**：遮罩出錯時，整列換成佔位文字；提問則不送出；工具呼叫也拒絕。寧可多擋，不放行原文。

## 遮哪些欄位

| 欄位 | 判定 | 遮罩 |
|---|---|---|
| 身分證、新式居留證（第二碼 8／9）、舊式居留證（第二碼 A–D） | regex 加**檢核碼**；全形、小寫也抓 | `A12****90`（前 3 碼＋`****`＋後 2 碼） |
| 病歷號 | **只遮有標籤的值**：`病歷號`、`病歷號碼`、`MRN`、`ChartNo`、`chart_no` 後面接 `:`、`：`、`=` 或空白；或表格（CSV／TSV／Markdown／JSON 二維陣列）中欄名是這些的那一欄 | `12****89`（頭尾各留 2 碼）；6 碼以下全遮成 `****` |
| 健保卡號 | 同上，標籤為 `健保卡號`、`健保卡號碼` | 同上 |

值必須含至少一個數字才算數，避免把 `chart no matter` 這類英文誤判成病歷號。

## 限制（不保證攔得到）

- **中文姓名、地址、電話、生日**：不處理。regex 誤判和漏抓都太多，請在資料源頭先去識別化。
- **沒有標籤的病歷號**：不處理，例如檔名或句子裡單獨出現的 `12345689`。
- **帶分隔符的 ID**（`A123-456-789`）、**base64／URL 編碼內容**：不處理。
- **圖片、掃描 PDF 的像素內容**：無法遮罩。只擋敏感目錄底下的檔案；其他位置放行，並用 toast 提示。
- **畫面與 transcript 檔的結構化紀錄**：依 engine 規格，工具結果的結構化紀錄（`toolUseResult`，也就是畫面顯示的內容）會原樣存進本機 transcript。**模型讀不到這份紀錄**，但它會留在本機磁碟上。
- **`--resume` 載入的舊對話**：載入不算 append，不會經過遮罩。啟用本 mod 之前的對話若含 PHI，resume 後模型會讀到原文。
- **每次請求才渲染、或帶有媒體的附件列**：依 engine 規格，這類列會保持原樣不改寫，詳見 debug log。
- **資料完整性守門的豁免**：`A12****90`、`12****89` 是 CLAUDE.md §4 的示範字樣，寫入時不擋。若真實資料的遮罩結果剛好等於這兩個字串，就會漏擋。
- **Bash 以外的間接寫入**：例如透過程式自己寫檔，不在守門範圍內。
- **Grep、`head`／`tail` 等片段輸出裡的表格欄**：表格欄是靠表頭判斷，片段輸出不含表頭，病歷號欄就**不會被遮**（身分證有檢核碼把關，不受影響）。含病歷號欄的表格請用 Read 讀整檔，不要用 Grep 查。
- **含遮罩字樣的檔案很難編輯**：資料完整性守門會擋下內容含遮罩字樣的 Write／Edit，包括本 mod 自己的測試檔。測試需要遮罩字樣時，請在執行時才組出字串（例如 `'*'.repeat(4)`），原始碼裡不要直接寫出四個連續星號。
- **engine 不認得的 block 類型**（例如 MCP 的 embedded resource）：engine 會原封放回，hook 無法改寫，也無法移除。
- **非文字的 document**（PDF base64 等）：無法掃描，原樣放行。文字型 document 只要命中識別資料，就整份移除（依規格，document 不能改寫）。
- **CSV 欄位內換行**（引號包住的多行欄位）：不支援，該列之後的表格欄可能失去對應。
- **路徑含 `..`**：只要字面路徑含敏感目錄就擋，即使實際落點已離開該目錄，偏向多擋。
- **未列在豁免清單的 MCP 工具**：輸入含遮罩字樣時一律擋下（未知即擋）。唯讀豁免目前只有 Google Sheets 的 `get_values`、`get_spreadsheet`。

## 開發與測試

```
claude plugin validate <本資料夾>
claude plugin test <本資料夾>
```

`tsc` 型別檢查：mod 被 engine 載入後會在 `.claude-plugin/types/` 產生型別與 tsconfig，之後執行 `tsc -p <本資料夾>` 即可。

測試用的身分證是用檢核碼演算法產生的合成值，不含任何真實個人資料。實機驗收用的合成檔在 `tests/fixtures/synthetic.tsv`。

**子代理涵蓋的實測方法**（測試環境無法啟動真實子代理）：叫子代理用 Read 讀 fixture，再請它把身分證欄位逐字以空白分隔輸出。加了空白的字串不會被遮，所以能直接看出子代理讀到的是原值還是遮罩值。2026-10-09 實測結果：子代理讀到的是遮罩值。
