# phi-guard-tw 規格（2026-10-09 需求確認定案）

## 目標
在模型讀到工具輸出和使用者提問之前，強制遮罩格式固定的台灣病患識別欄位。這讓全域 CLAUDE.md §4 的遮罩規則從「靠模型記得」變成「程式強制」。

## 驗收條款

- **S1 欄位**：身分證、新式居留證（第二碼 8／9）、舊式居留證（第二碼 A–D），用 regex 判斷並驗證**檢核碼**；病歷號、健保卡號**只遮有標籤的值**。標籤為 `病歷號`、`病歷號碼`、`MRN`、`ChartNo`、`chart_no`、`健保卡號`、`健保卡號碼`，後面接 `:`、`：`、`=` 或空白；或表格中欄名是這些標籤的那一欄。
- **S2 不做**：中文姓名、地址、電話、生日、帶分隔符的 ID、base64 或 URL 編碼內容。這些都寫在 README 的限制裡。
- **S3 遮罩格式**：身分證保留前 3 碼，接 `****`，再保留後 2 碼；病歷號頭尾各留 2 碼，**6 碼以下全遮**（原定 4 碼以下，後改為更嚴的 6 碼）。病歷號的值必須含至少一個數字。
- **S4 範圍**：全域生效。遮罩對象是所有寫進對話的資料，包括工具輸出（含 MCP）、附件和子代理的對話。走訪 result 或 content 時保留原本結構。文字型 document 依契約不能改寫，命中識別資料時整份移除。engine 會原封放回的未知 block（如 MCP resource）不在保證範圍內（2026-10-09 依 Codex 覆核修訂）。
- **S5 提問**：送出前直接把值遮掉（不是整則擋下），並用 toast 回報欄位類型和數量，不顯示原值。
- **S6 失敗時擋下**：守門程式出錯時寧可多擋。工具呼叫直接拒絕；對話中的資料：text 和 tool_result 的內容換成佔位文字，image 和 document 移除；tool_use、thinking 和未知 block 由 engine 原封放回，不在保證範圍內。提問不送出（2026-10-09 依 Codex 覆核修訂）。
- **S7 資料完整性**：工具輸入含本 mod 產生的遮罩字樣時擋下，以免把遮罩值寫回來源。讀取類工具和代理之間傳訊息的工具豁免。CLAUDE.md §4 的兩個示範字樣 `A12****90`、`12****89` 也豁免。
- **S8 正規化**：全形轉半形，比對不分大小寫。
- **S9 圖片與 PDF**：路徑中有 `00_private`、`raw`、`private`、`phi` 目錄時，擋下對圖片或 PDF 的 Read；其他位置放行，並提示「圖片未經 PHI 掃描」（實作用 toast）。
- **S10 大型輸出**：全量掃描，不設上限跳過。
- **S11 驗收**：單元測試、合成 fixture 實機測試、子代理涵蓋實測、5 MB 處理時間；`validate` 與 `tsc` 無錯誤。

## 架構決策
- 用 mod 的 function hooks：`session.append` 是主要遮罩點，`prompt.submit` 處理提問，`tool.call` 做守門。
- 遮罩邏輯集中在 `hooks/mask.ts`，全部是純函式。
